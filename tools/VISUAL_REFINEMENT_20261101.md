# 三体控制台视觉优化交付

本轮目标：保留液态玻璃与既有操作习惯，把工作台做得更克制、清晰、一致。采用 CSS 透光、边缘高光、背景模糊模拟光学玻璃，并非 Apple 原生材质。

## 后续材质增强：恢复明确的液态玻璃辨识度

用户反馈上一版太像普通磨砂面板后，进一步调整 `public/visual-refinement.css`：

- 增强背景边缘的香槟、冰蓝与青色光场，正文中央保留较暗/较浅的稳定阅读底色。
- 降低大面板填色遮蔽，加入角落弧面反光、底部透光与方向性折射亮边。
- 玻璃使用外缘高光和内侧细边表现厚度；高光层 `pointer-events:none`，不拦截按钮或文字选择。
- 输入框、工具栏、侧栏、任务抽屉、监控面板同步更新；维持现有排版与输入文案。
- 菜单、任务等浮层仍有较强底色；减少透明度和流畅模式继续提供实色回退。不新增持续光效动画。

增强后重新运行同一隔离 Electron 验证，34 项通过，渲染器错误 0。已核对暗/亮阅读区、暗色抽屉及监控截图；`tools/visual-*.png` 为增强后版本。未新增原生鼠标或长时性能验收。

增强前样式和截图保存在 `_archive/glass-depth-20261101`；仅撤销此次材质增强时，将其中 `visual-refinement.css` 恢复到 `runtime/resources/app/public/visual-refinement.css` 即可。

## 对应实现

| 约定方向 | 本轮实现 |
| --- | --- |
| 材质分层 | 导航、输入框用轻玻璃；消息与内层列表减少重框；菜单、设置、任务和对话框使用更高不透明度的磨砂底色。统一边缘、阴影与饱和度。 |
| 阅读优先 | 消息列最大 880px；增加段落、列表、标题间距；调整代码块、用户气泡、辅助文字；降低背景颗粒与光斑强度。 |
| 侧栏层级 | 统一代理、项目、会话行的间距和字号；减弱计数、额度卡与内层边框；会话选中、悬停、键盘焦点分开处理，保留项目失焦淡化。 |
| 字体与尺寸 | 工作台标题、监控标题统一系统无衬线；正文、辅助说明、数字与等宽代码分级；共享圆角、控件尺寸和间距。保留输入框原文案。 |
| 品牌与语义色 | 冰蓝、青色、香槟色贯穿两种主题；代理各自保留颜色；等待、失败、本轮结束与执行中有不同状态边线，文字状态仍保留，不能仅靠颜色识别。 |
| 动效与状态 | 菜单和浮层 200ms 轻入场；按钮 140ms 反馈；任务列表新增空状态说明；读取提示、错误提示统一样式；键盘焦点和禁用状态统一；减少动效、减少透明度、流畅模式与强制颜色模式提供回退。 |

## 改动位置

- `runtime/resources/app/public/visual-refinement.css`：工作台与监控台共享的视觉层。
- `public/workbench-ui.js`：加载视觉层、任务状态属性、空任务提示。
- `public/app-ui.js`：新建项目空状态文案与文件夹选择行为一致。
- `public/index.html`：搜索输入可访问名称、去掉设置里的旧固定帧率宣传。
- `public/monitor/index.html`：接入共享样式与监控作用域。

未修改模型调用、权限、存储协议、历史内容、产物数量、登录流程；WorkBuddy 按用户要求继续搁置。

## 验证

`tools/verify-visual-refinement.cjs` 在独立 Electron 渲染器、独立数据目录及 worker 下运行。`tools/visual-refinement-results.json` 记录 34 项通过，渲染器错误 0。

覆盖明暗主题、任务空状态、抽屉关闭按钮 DOM 上中下命中、更多菜单视口边界、800/1024/1280/1440 宽度布局与发送按钮、输入原文案、流畅模式、减少透明度与动效、切入监控时关闭抽屉、监控窄屏横向溢出。

截图在 `tools/visual-*.png`。阅读截图里的对话是临时 UI 样例，未写入正式会话；监控使用隔离配置，没有填造真实会话进度。暗色阅读、亮色阅读、暗色抽屉及亮色监控截图已人工视觉核对。

验证边界：按钮命中为渲染器检查，不等同于原生 Windows 鼠标复测；未做长时性能/帧率验收，也未重新测试原生模型执行。无新增持续背景动画，未给每行内容增加模糊。
