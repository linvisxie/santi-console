## 可用性

1. 新会话先进入项目草稿，反复点击不发创建请求、不清空输入。第一次发送非空消息后才创建记录；只浏览文件也不会创建空会话。旧的无内容、无原生绑定、默认名空记录在会话列表中隐藏，未删除历史文件。
2. 任务抽屉/菜单/弹窗及子节点明确排除窗口拖拽，浮层打开期间禁用下方标题区的拖拽；关闭按钮最小 44×36 CSS 像素。
3. 右侧栏顶部新增就近关闭按钮，按钮行避开原生窗口控制区。
4. 进入监控台收起任务抽屉、更多菜单、工作台弹窗、设置、右键菜单与选中文本浮条；CSS 进一步隔离工作台浮层，返回不自动重开。
5. DSH 按最近文件更新时间排序，不再把今天续作的老会话留在创建日期。采用最新原生 session/title；首帧读取不再依赖不完整的 8KiB 压缩片段。近期有执行事件的会话标“执行中”，不只根据文件变化判忙。
6. 共用 lib/dsh-events.mjs 解析真实提问、思考、回复、工具调用、嵌套 PTC 调用和工具结果，历史保留完整内容，监控摘要限制另设。监控不再只显示目录占位；各代理保留自己的近期流条目，避免高频 Codex 把 DSH 全部挤出来源筛选。
7. 新建项目默认调用 Electron 原生系统文件夹选择器；取消不添加、重复点击不叠加选择器；Shift+点击保留手动路径入口，普通浏览器无原生 API 时仍可输入。新目录归当前所选代理，兼容原有项目。此项修改 main/preload，必须重开应用才能加载桥接方法。
